## 수량 행 간격 종료 기준 적용 후

금액 단어 사이를 자르는 방법은 사용자 변경 지시에 따라 구현에서 제거했다. 수량 열에서 겹친 중복 박스를 한 행으로 묶고, 인접 수량 중심의 간격 중앙값(짝수일 때 작은 쪽)을 기준으로3배 이상 끊긴 지점을 찾는다. 뒤 숫자가 없어도 사진 끝까지 세 행 분량이 비어 있으면 마지막 수량 행에서 멈춘다. 마지막 행의 이름·금액 높이 오차를 위해 간격의25% 아래 여백만 허용한다. 수량 행이3개 미만이면 종료 위치를 추측하지 않는다. 전체 OCR 수량을 우선 활용하고 필요한 수량 열 OCR에서 확인한 위치로 보완한다.

같은 사진과 첫 상품 기준을 수정 코드로 hot restart한 에뮬레이터에서 실제 ML Kit로 재실행했다. 구매 상품15개 모두 기존 수량·금액과 일치, 검토 후보17개(구매15개·중간 포인트카드2개 체크 해제), 이름 열 OCR1회, 수량/금액 열 OCR0회, 부분 OCR0회다. 탐색 하단은 원본 사진 좌표1123.25px(표시 반올림1123.3)로 제한됐고 마지막 마미손을 유지했다. 전체 후보34개/숫자59개는 그대로 누적 저장소에 보존된다. 실행시간7.429초는1회 실측으로 일반적인 성능을 보장하지 않는다. `quantity-gap.tsv`에 실제 응답을 기록했다.

이 기준은 인식된 수량 위치에 의존한다. 실제 상품 중간에서도 세 행 이상 수량을 연속으로 놓치면 그 위에서 종료될 수 있으며, 원문 후보를 버리지는 않는다. APK 재빌드·재설치는 아직 하지 않았다.
