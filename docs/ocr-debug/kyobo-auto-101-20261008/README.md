# 교보 101 자동 수량 연결 — 2026-10-08

- 문제는 101을 첫 기준으로 선택하면 정상인데 포스트잇 다음 상품으로 자동 처리하면 수량이 빠지는 것이다. 첫 기준의 정상 동작은 사용자 확인이다. `before-review.png`는 연결된 삼성 SM-A336N의 실제 검토 화면이며101의 수량 실패·체크 해제를 확인했다. 구매 기록은 저장하지 않았다.
- 실제 설치 APK는 `ef8af56f4d65f7dcce9b222ead003999e1e778753ce727bcc818aa27ac371c1e`다. 앞선 수정으로 초기101 수량 박스는 하나가 됐지만 자동 연결은 다른 중복 조건을 사용했다.
- 실기기 초기 화면에서 확인한 두1의 작은 가로 틈은 `../kyobo-phone-boxes-20261008/`에 보존했다. 원문에 두 후보를 유지하는 것과 자동 연결에서 둘을 별개 숫자로 세는 것은 다르다. 기존 `receiptNumbersWithCandidates`는 가로 틈을 허용하지 않아 두1을 남겼고, 자동 연결은 후보가 정확히1개인 경우에만 수량을 확정했다. 첫 기준은 사용자가 고른 수량을 직접 사용하므로 이 조건을 우회했다. 숫자 열 행 선택도 중복 행을 별개로 세는 문제가 있었다.
