## 적용 범위와 오인식 방지

자동 선택의 누락 수량 재인식에서 첫 수량과 금액 박스 사이의 가로 간격만큼 좌우 문맥을 추가한다. 세로 범위는 기존 수량 탐색 박스를 유지한다. 결과 숫자는 원본 좌표로 환산하여 수량 박스 안에 중심이 있는 것만 취한다. 중복된 같은 값은 합치고 서로 다른 값·0·범위 밖 값·빈 결과는 확정하지 않는다. 기존 전체 OCR/수량 열 후보 재사용, 최대 5회·첫 성공 확정, 취소·병렬 인식기 정리 흐름은 유지한다. 수동 영역 다시 읽기의 범위는 이번 변경 대상이 아니다.

회귀 테스트의 응답은 모의다. 실제 PNG 크롭 범위, 수량 박스 밖 가격/할인/다른 행 제외, 중복 1, 충돌 값, I, 0, 빈 수량을 검사한다.

## 시험 환경

첫 통합 테스트에서 Flutter 도구의 종료 후 앱 삭제 기본값을 놓쳐 에뮬레이터 앱과 테스트 기록이 제거됐다. 테스트 전 APK를 재설치했다. 사용자는 테스트 기록이라 복원이 필요 없다고 확인했다. 이후 시험은 별도 패키지 `com.todayone.todo.ocrprobe`와 `--no-uninstall`로 실행했다. 임시 applicationId와 사진 에셋 설정은 시험 후 원래 바이트로 복원했다. 패키지 준비·업그레이드는 하지 않았다.


검증: 실제 네이티브 비교92회와 적용 서비스23영역 시험 완료. 모의 회귀를 포함한 전체 Flutter 테스트274개 통과·기존1개 건너뜀. 포맷 완료, 정적 검사는 기존 `screens.dart:806` 경고1개만 남았다. 임시 에셋/applicationId 및 생성 등록 파일은 시험 전과 동일하다. 패키지 준비·업그레이드·새 배포 APK·커밋·푸시는 하지 않았다. 에뮬레이터의 일반 앱은 시험 전 APK이며 변경 코드의 설치는 별도 요청 시 진행한다.
