# 배포 전 확인

| 항목 | 상태 | 확인할 내용 |
|---|---|---|
| Android 운영 서명 | 재검토 필요 | debug 서명을 스토어 운영 키로 교체 |
| iOS 서명·설치 | 완료 | 팀 2263MJ8YV6, 아이폰 1.5.1(18) 업데이트·실행 |
| iOS 27 호환성 | 완료 | UIScene 전환, iOS 27.0.1 아이폰에 1.5.2(19) 유선 업데이트·재실행·기존 저장값 보존 |
| 클러스터 DB·API | 완료 | PostgreSQL 17, PVC 2Gi, HTTPS·Swagger·DB 재시작 보존 검증 |
| DB 가용성 | 재검토 필요 | 단일 DB·Longhorn 복제 1개, worker-kr-1 장애 시 수동 전환 |
| 수동 백업 복원 | 완료 | 실제 pg_dump를 별도 로컬 DB에 복원, 3개 테이블 확인 |
| 아이폰 자동 통합 테스트 | 보류 | 무선 VM Service 연결 미확인. USB로 Keychain 검사 필요 |
| 자동 백업 | 미시작 | 저장 위치·주기·복원 훈련 결정. Retain은 백업 아님 |
| 저장 한도 | 완료 | 계정 1,000행·200KB, 본문 1MiB, 실패 시 기기 기록 유지 |
| PVC 용량 | 재검토 필요 | 70%부터 확장 검토. max_wal_size는 디스크 절대 상한 아님 |
| 요청 제한 | 재검토 필요 | 현재 API 한 프로세스. replica 확장 전 게이트웨이 제한 필요 |
| 세션 정책 | 재검토 필요 | 365일·계정당 최근 20개. 오프라인 로그아웃은 기기 토큰만 제거 |
| 복구 코드 정책 | 재검토 필요 | 일회 표시·분실·유출 안내, 교체·폐기는 후속 |
| Harbor pull 자격 증명 | 재검토 필요 | howmuch-pull robot 365일 만료 전 교체 |
| 배포 운영 | 완료 | how-much 저장소의 수동 kubectl 배포, 공용 Gateway·인프라 저장소 변경 없음 |
| 실기기 OCR | 재검토 필요 | 한국어 메모·영수증 실제 표본 확인 |
| 기존 데이터 이관 | 재검토 필요 | 필요 시 React Native·기존 Firebase 별도 이관 |
| 두 물리 기기 동기화 | 재검토 필요 | 실제 서버 동시 요청 검증 완료. 두 아이폰 실사용은 별도 |
