# Figma 기반 장보기 UI

## 1. 작업 출처
사용자 요청(2026-10-05), Issue #3, #6. [Figma 설계](https://www.figma.com/design/3V6S4dhhntbYRT5iLg31EE/).

## 2. 배경
기존 녹색 화면을 Figma의 크림·오렌지 장보기 설계로 바꾼다.

## 3. 목표
장보기 메모와 실제 구매 가격 흐름을 구분하고 화면을 쉽게 읽을 수 있게 한다.

## 4. 범위
홈·상품 수정·메모 촬영/검토·영수증 촬영/검토·구매 기록·가격 비교, 로컬 SVG와 글꼴, 루트 AGENTS.md.

## 5. 구현해야 할 것
- [x] 설계 색상·Jua/Noto Sans KR/Gaegu 글꼴·원본 SVG
- [x] 장보기·구매 기록 하단 탭
- [x] 촬영과 직접 입력, 품목을 눌러 수정하는 검토 화면
- [x] 영수증별 기록·검색·이번 달·금액순 정렬
- [x] 확인된 동일 규격의 최근 30일 가격 비교
- [x] 작은 화면·키보드·주요 화면 이동 검증

## 6. 현재 구현 상태
| 항목 | 상태 | 비고 |
|---|---|---|
| Flutter 화면 | 완료 | 기존 저장·OCR·공유 로직 유지 |
| 화면 렌더링 | 완료 | 390×844에서 홈·기록·수정·검토·가격 비교 확인 |
| 작은 화면 | 완료 | 320×568, 키보드 표시 상태 검증 |
| 실기기 촬영·OCR | 재검토 필요 | 실제 카메라 프리뷰와 권한·배경 복귀 확인 |

## 7. 다음에 바로 해야 할 것
실기기에서 메모·영수증 표본으로 촬영과 오인식 수정 흐름을 확인한다.

## 8. 후속에 구현해야 할 것
접근성 글자 크기와 실제 OCR 표본을 추가 검증한다.

## 9. 결정된 사항
- 홈의 메모는 장보기 목록으로, 구매 기록의 영수증은 구매 이력으로 저장한다.
- 원본 SVG는 `app/assets/figma/`에서 불러온다. 임시 Figma URL을 앱에 남기지 않는다.
- 카메라 영역과 가격 그래프는 실제 영상·실제 데이터로 표시한다. 설계의 샘플 품목이나 그래프를 사용자 기록으로 보여주지 않는다.
- 비교 조건이 확인되지 않은 기록은 최저가·평균 계산에서 제외한다.
- 추가 기능인 품목 입력·할인 조건·가격 공유는 기존 동작을 보존한다.

## 10. 아직 결정되지 않은 사항
실기기 표본과 운영 가격 공유 정책.

## 11. 임시 구현 / 주의사항
렌더링 검증의 예시 상품은 테스트 데이터다. 앱에는 초기 샘플 기록을 넣지 않는다. iOS 빌드·실기기 제한은 배포 전 확인 문서에서 관리한다.

## 12. 변경 이력
2026-10-05: Figma 화면과 한국어 개발·주석 기준 적용.
